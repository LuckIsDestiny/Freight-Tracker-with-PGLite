# Curriculum

## Phase 0: Learning how to learn
0. Documentation, error messages, effective search, and research habits

## Phase 1: Foundations
1. How the web works
2. HTML semantics and CSS
3. JavaScript deep dive
4. Async JavaScript
5. Git, GitHub, terminal, npm, and package.json

## Phase 2: Frontend with React
6. Why React exists
7. JSX, components, props, and composition
8. State, events, conditional rendering, and lists
9. useEffect, data fetching, loading and error states
10. Forms and validation
11. React Router
12. State management
13. Custom hooks and performance basics
14. Styling and accessibility

## Phase 3: Backend with Node.js
15. Node fundamentals and plain http server
16. Express routing and middleware
17. REST API design
18. Environment variables, logging, and project structure

## Phase 4: SQL and PostgreSQL with PGlite
19. Relational database concepts
20. PGlite setup and Node SQL shell
21. CRUD and SQL fundamentals
22. Joins, aggregation, subqueries, CTEs, and window functions
23. Relationships and join tables
24. Indexes and query performance
25. Transactions and ACID
26. PGlite socket server and node-postgres
27. Hand-written migrations and seeds
28. Raw SQL data-access layer

## Phase 5: Full-stack integration
29. Connecting React to Express
30. Authentication from scratch
31. Authorization and security
32. File uploads and cross-stack error handling
33. Testing
34. Deployment and hosted PostgreSQL
35. TypeScript, WebSockets, caching, and background jobs

# Capstone projects

Build these gradually:
- Todo app
- Notes app with authentication
- Blog/CMS with comments and tags
